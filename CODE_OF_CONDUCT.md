# Code of Conduct

ScholarSkills is an academic collaboration across institutions and career stages. The standard is
the one expected in a well-run seminar: argue about the work, not about the person.

## Expected

- Critique methods, code and evidence directly and specifically.
- Assume good faith while requiring evidence; "it works on my machine" is a starting point, not a
  proof.
- Attribute ideas and prior work, including work by people outside the project.
- Respect data protection: never paste personal data, private messages or identifiable information
  from a corpus into an issue, a review or a test fixture.

## Not accepted

- Harassment, discriminatory language, or personal attacks.
- Publishing someone else's unpublished data or code without consent.
- Pressuring reviewers to grant a maturity level the evidence does not support.
- Claiming external endorsement (institutional, editorial or platform) that the project does not
  have.

## Enforcement

Concerns are reported to the maintainers listed in `CITATION.cff`. Maintainers may edit or remove
contributions that violate this code, and may decline further participation. Reports are handled
confidentially.
