# Example output

Synthetic output produced by the client, included so that a reader can see the shape of the
artefact without running anything and without touching a real library.

`sample_bibtex.bib` shows what `zotero_bibliography.py --collection ABC123 --format bibtex`
writes. The records are fabricated for illustration; the DOIs point to the format documentation,
not to fabricated research.

`sample_provenance.json` shows the stderr record: library type, library id, reference count,
number of API requests, timestamp. Note that it carries **no** credential — that is a test case, not
a convention.
