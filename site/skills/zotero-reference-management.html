Gestão de referências Zotero para pipelines de pesquisa

Ler, buscar, exportar e criar referências Zotero pela Web API v3, sob o princípio de que a chave de API é o limite de acesso.

Requisitos

O que você precisa ter antes de rodar esta skill. Tudo o que é exigido aparece aqui — inclusive credenciais.

Chave de API do Zotero

ObrigatóriocredencialZOTERO_API_KEY

O que é: Uma chave pessoal criada na sua conta Zotero. É ela que autoriza a skill a ler (e, se você permitir, gravar) na sua biblioteca.

Como obter: Zotero → Settings → Security → Applications → Create new private key. Marque apenas as permissões que você quer conceder: leitura da biblioteca, leitura/escrita se for criar referências, e acesso à biblioteca privada se for o caso. Copie a chave no momento da criação — ela não é exibida de novo.

export ZOTERO_API_KEY="sua_chave_aqui"
Criar chave no Zotero ↗Documentação da Web API v3 ↗

Cuidado: A chave é uma credencial: não a coloque no código, em repositório, em notebook versionado nem em captura de tela. Use variável de ambiente.

ID da biblioteca

ObrigatórioidentificadorZOTERO_LIBRARY_ID

O que é: O número da sua biblioteca (userID). Aparece na mesma página de chaves, junto ao seu nome de usuário.

Como obter: Na página de configurações de chaves, o número ao lado do seu nome de usuário é o library ID. Para bibliotecas de grupo, use o ID do grupo.

export ZOTERO_LIBRARY_ID="123456"
Ver seu ID ↗

Cuidado: Não é secreto, mas identifica sua conta: prefira não publicar junto com dados de pesquisa.

Tipo de biblioteca

ObrigatórioconfiguraçãoZOTERO_LIBRARY_TYPE

O que é: Diz se a biblioteca é pessoal (user) ou de grupo (group).

Como obter: Biblioteca pessoal → user. Biblioteca compartilhada de um grupo → group (e o ID passa a ser o do grupo).

export ZOTERO_LIBRARY_TYPE="user"   # ou "group"

Cuidado: Não é credencial; define qual endpoint o cliente consulta.

Objetivo

Converter uma biblioteca Zotero em fonte de dados confiável e citável para pipelines de pesquisa: enumerar, filtrar, exportar e gravar referências pela Web API v3 — sem navegador, sem scraping e sem identificadores pessoais no pacote.

Recursos

Web API v3Exporta BibTeX/CSLEscopo da chave respeitado

Como funciona

  1. Resolver a biblioteca com GET /keys/{key}: o userID numérico e o escopo de permissão.
  2. Contar pelo cabeçalho Total-Results com itemType=-attachment, nunca pelo tamanho de uma página.
  3. Paginar com start até vir uma página vazia — não por um número fixo de iterações.
  4. Exportar para BibTeX, RIS ou CSL JSON; por coleção em bibliotecas grandes, porque a exportação BibTeX ignora o limite.
  5. Gravar com POST de um array JSON, e só quando o escopo da chave permitir.
  6. Recusar com clareza: um 403 é reportado como limite de escopo, jamais contornado.
