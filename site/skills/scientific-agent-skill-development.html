Scientific Agent Skill Development and Validation Protocol

Meta-skill that lets an agent create, document, test and prepare a scientific skill for deposit.

SS-0000 Tested Available v1.0.0 ·MIT (code) / CC-BY-4.0 (docs)

Objective

A meta-skill: it turns a research method into a documented, tested, citable agent skill — or refuses, and says why.

How it works

  1. Scope the claim in one falsifiable sentence; an unfillable slot is the finding, not an obstacle.
  2. Ground the method in verifiable literature, separating established fact, interpretation, hypothesis and normative position.
  3. Generate the canonical package (SKILL.md, README, CITATION.cff, LICENSE, .zenodo.json, references, tests).
  4. Write tests that can fail: positive, negative, edge, tool failure, absent reference.
  5. Record the real environment and the real output; a result without its environment is a report, not a reproduction.
  6. Audit ethics and rights: personal data, consent, copyright, dual use, attribution.
  7. Validate structure, then prepare — never perform — the deposit.

Validation

Structural validation proves conformance to the Agent Skills specification and the completeness of the package. It does not prove that the method is correct. Evidence for this skill's maturity level: scientific-agent-skill-development/tests/RESULTS.md.
