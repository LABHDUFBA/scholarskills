Configuração de repositórios de pesquisa

Planejar ou revisar um repositório de pesquisa examinando escopo, materiais, proveniência, limites de tratamento de dados e estado do controle de versão, sem impor uma estrutura universal.

Requisitos

O que você precisa ter antes de rodar esta skill. Tudo o que é exigido aparece aqui — inclusive credenciais.

Opcionalsoftware

O que é: Executa o script opcional que cria uma estrutura inicial de documentação.

Como obter: Verifique com python3 --version. O teste local foi executado em Python 3.14.9; a CI verifica Python 3.10 e 3.12.

Baixar Python ↗

Cuidado: O procedimento pode ser seguido sem o script. O script não inicializa Git nem move dados.

Objetivo

Ajudar pesquisadores e agentes a criar ou revisar um repositório ajustado ao projeto, com documentação e proveniência que tornem o trabalho navegável e rastreável, mantendo materiais sensíveis e ações irreversíveis sob controle humano.

Recursos

Estrutura adaptada ao projetoProveniência documentadaEsqueleto não destrutivo

Como funciona

  1. Inspecionar o brief, arquivos existentes, estado do Git, branch, remotes e documentos de referência antes de editar.
  2. Definir limite do projeto, objetivo, produtos, não-objetivos, equipe, restrições e critérios de conclusão.
  3. Classificar materiais sensíveis, restritos, de terceiros, gerados ou volumosos antes de mover ou preparar qualquer arquivo.
  4. Escolher uma estrutura específica para o projeto e criar apenas a documentação necessária.
  5. Registrar proveniência, unidades, snapshots, filtros, transformações e ambiente para produtos dependentes de dados.
  6. Conferir diff e testes; nunca migrar, commitar, enviar ou publicar sem autorização explícita.
