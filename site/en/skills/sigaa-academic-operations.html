SIGAA Academic Operations

Prepare and safely execute teaching and research operations in SIGAA-like academic portals with explicit approval gates, side-effect disclosure and post-action verification.

SS-0015 Tested Available Foundation v0.1.0· MIT
View repository ↗ View package ↗ Install Cite
Python

What it solves

Structure human-in-the-loop work in stateful academic portals: identify the target, validate inputs, prepare a reversible draft, obtain approval before persistence, and read back the result.

Installation and activation

This package publishes no installation commands.

  1. Copy the package directory into your agent's skills folder.
  2. Start a new session so the agent re-reads its skills.
  3. Confirm the skill appears in the environment's list before using it.
  4. Only then ask for the task, within the scope and permissions you granted.

In Hermes Agent: hermes skills list and, in session, /skill <name>.

In Claude Code: the directory name becomes the /name command.

How it works

  1. Identify institution, profile, module, term and target record.
  2. Discover the current interface by semantic labels instead of permanent selectors.
  3. Validate fields, dates, files, call requirements and side effects.
  4. Prepare the operation without saving, publishing, approving or submitting.
  5. Show the target and diff; require explicit human approval.
  6. Persist once, read back the target and report the observed result.
