Hugo Site Maintenance for Research Websites

Keep a Hugo site correct while it is edited: inspect before creating, compare the published site with the clone, audit front matter and broken links, and read the deploy run instead of rewriting the build.

Requirements

What you must have before running this skill. Everything required appears here — credentials included.

Hugo extended 0.110+

Requiredsoftware

What it is: The extended Hugo binary, which supports SCSS and Hugo Pipes.

How to get it: Download the hugo_extended tarball from the release and put it in ~/.local/bin. Check with hugo version.

Install Hugo ↗

Careful: Match the version used by the CI workflow; divergent versions build differently from what is published.

Python 3.10 or newer

Requiredsoftware

What it is: To run the front matter and link audit.

How to get it: Check with python3 --version.

Download Python ↗

Careful: No credential: the deploy uses the repository's own token in Actions.

Objective

Keep a Hugo site correct while it is being edited: inspect before creating, compare published with the clone, and read the deploy run before touching the build.
