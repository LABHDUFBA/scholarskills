Models, agents, skills and tools

The minimum vocabulary for reading the catalogue without confusing prompt, plugin, method and tool.

The use of artificial intelligence in scientific research is not limited to interacting with language models through prompts. Agentic systems combine models, coordination mechanisms, procedural resources and computational tools. Understanding these components helps explain how research procedures can be documented and mobilised by AI agents under human supervision.

Large language models (LLMs): interpretation and generation

Large language models are AI models trained to process and generate language. Some add multimodal capabilities and can also work with images, audio and other data types. In agentic systems, these models can interpret instructions, propose actions and select operations according to the resources the system makes available. Examples: the GPT, Claude, Qwen and Llama families.

AI agents: task coordination

An agent is a system that uses one or more AI models to pursue goals through steps of decision and action. Depending on its architecture, it can keep state, retrieve information, call tools, evaluate results and request human intervention. Examples of agent environments: Hermes Agent and Claude Code. Autonomy is not the same as reliability.

Skills: reusable procedural knowledge

A skill is a package of instructions and resources that guides an agent through a bounded task. It may combine procedures, decision criteria, references, scripts, examples and tests. Unlike a one-off instruction, it can be organised, versioned, distributed and reused across tasks and compatible environments. Prompts may be part of a skill; plugins may provide resources a skill uses. The categories are not mutually exclusive.

Tools: execution resources

Tools are interfaces or resources that let the agent perform specific operations, such as running Python code, querying an API, retrieving Zotero references or searching Elasticsearch. The tool exposes an operation; the skill can guide its selection, use and verification criteria.

Teaching summary: the model interprets and generates, the agent coordinates, the skill guides and the tool executes operations. This is a simplification: the functions can overlap depending on the architecture.

What is a scientific skill in ScholarSkills?

In ScholarSkills, a scientific skill is a documented package that operationalises methodological procedures or research-support activities. The project's editorial proposal adds requirements of grounding, transparency, assessment, authorship and explicit limits to the technical Agent Skills format.

A skill should state, as its purpose requires: objective and conditions of use; inputs and outputs; requirements and permissions; procedure and stop criteria; verifiable references; tests and evidence; methodological, ethical and legal limits; version, licence, authorship and citation when available.

Operationalising a procedure does not guarantee scientific validity, nor does it automatically turn results into reliable evidence. Responsibility for research design, interpretation and assessment remains human.

A concrete example: Zotero (SS-0001)

A researcher asks for an export of the references in a collection. The agent interprets the request with an LLM, consults skill SS-0001 for the procedure and access conditions, uses the Zotero API with adequate permissions and returns the records for checking. The quality of the references and their fit to the research remain subject to human assessment.

Illustrative example. It is not a report of a test run in this revision.

Normative and terminological basis

The open Agent Skills specification defines the minimum technical format: a SKILL.md file with YAML frontmatter containing name and description, plus optional resources. ScholarSkills adds its own editorial and scientific requirements, described in the editorial policy.

README, DOI, tests, peer review and CITATION.cff are not universal requirements of the specification: they are this project's choices for making provenance and assessment explicit.
