Contribute a skill

A skill here is a package that describes a research method, runs tests and can be cited. To propose one you do not need to write code alone: fill the brief and hand it to your agent — the SS-0000 protocol does the rest.

Download the brief (.md) Read the contribution guide

  1. 1
    Download the brief

    A Markdown file with the questions that define the skill: task, data source, limits, evidence and authorship.

  2. 2
    Fill it with your agent

    The brief ends with instructions to the agent. An empty field is a question to ask, not a gap to invent.

  3. 3
    Open a proposal

    Send the resulting directory as a pull request. Review looks at the method and the evidence, not at popularity.

    Read the contribution guide →

What review checks

  • The skill declares its research stage and the discipline it serves.
  • Every execution requirement is listed: credential, environment variable, software.
  • A limits section exists: what the skill does not do and does not prove.
  • Tests run offline and tests/RESULTS.md carries the real environment and output.
  • No credential, local path or personal data in the package.
